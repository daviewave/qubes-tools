#-- overview --#
- by default nss stores credentials for passwd, group, shadow, and gshadow in /etc clear text files
- not secure, so want to use berkely db's instead with special nss db packages instead

#-- setup --#
#->(debian)
	- install 'libnss-db' with apt
	- after installing, go to /var/lib/misc
	- compile the Makefile
	- edit /etc/nsswitch.conf to use 'db' & prevent files from being used

#->(fedora)
	- install 'nss_db' with dnf
	- after installing go to /var/db (glibc's nss_db reads /var/db on fedora, not /var/lib/misc)
	- compile the Makefile (it runs makedb for each of passwd, group, shadow, gshadow, ...)
		- single file by hand: makedb -o /var/db/passwd.db /etc/passwd

#-- automated --#
- ../setup_nss_db.sh installs the package, builds the db files, checks root resolves through
  'getent -s db', and with --switch points nsswitch.conf at db (backing it up first)
- the db files are a snapshot: rebuild with 'make -C <db dir>' after any user/group change
